# Memorial & Legacy Design System

An intentional, warm, and dignified design language crafted specifically for memorial, tribute, and heritage archive websites.

## Core Philosophy

- **Emotional Weight & Dignity**: Replaces utilitarian SaaS borders, intense vibrant primaries, and cold neon shadows with warm parchment tones, natural botanical greens, and antique brushed gold.
- **Generous Whitespace**: Ample vertical breathing room (`6rem` to `8rem` section padding) invites contemplation and avoids visual overwhelm.
- **Strict Light Mode**: Avoids stark dark modes that feel technical or cold. Uses layered warm ivory and soft alabaster cards to create depth without high-contrast black.
- **Thoughtful Typography Pairings**:
  - **Headings**: Editorial serif (`Cormorant Garamond` / `Playfair Display`) lends gravitas, warmth, and literary memory.
  - **Body**: Clean, humanistic sans-serif (`Plus Jakarta Sans` / `Inter`) provides effortless legibility across memories and condolences.
